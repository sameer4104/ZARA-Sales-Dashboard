# ZARA Retail Analytics Dashboard

A 3-page interactive Excel dashboard that analyzes ZARA retail sales, customer behavior, product performance, and store returns.

## 📌 Project Overview
The goal of this project is to turn raw ZARA sales data into clear, decision-ready insights. The dashboard helps answer questions like:
- How are overall sales and revenue performing?
- Which products and customer segments drive the most sales?
- Which stores perform best, and where are returns highest?

## 📊 Dashboard Pages
1. **Executive Sales Overview**: key KPIs, sales trends, and top-level performance
2. **Customer & Product Insights**: customer segments, best-selling products, and categories
3. **Store & Return Analytics**: store-wise performance and return analysis
